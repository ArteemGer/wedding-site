# Подключение Google Таблицы к приглашению

Код сайта уже подготовлен. До добавления адреса веб-приложения анкета остаётся в режиме локального черновика.

## 1. Создайте таблицу

Создайте новую Google Таблицу, например «Свадьба — Иван и Ангелина».
В ней выберите **Расширения → Apps Script**. Важно открыть редактор именно из нужной таблицы.

## 2. Вставьте скрипт и создайте листы

1. Откройте соседний файл `Code.gs` в проекте сайта и скопируйте его целиком.
2. В редакторе Apps Script замените стандартный код в файле `Код.gs` / `Code.gs` этим кодом и сохраните.
3. В выпадающем списке функций сверху выберите **setup** и нажмите **Выполнить**.
4. Google попросит разрешить вашему скрипту доступ к таблицам. Выполните авторизацию под своим аккаунтом. Если Google не позволяет авторизовать проект, остановитесь и проверьте сообщение об ошибке и ограничения аккаунта.
5. Вернитесь в таблицу: появятся листы **Ответы** и **Итого**. Первый содержит анкеты, второй автоматически считает выбранные напитки. Часовой пояс таблицы — Москва.

Не запускайте `doPost` кнопкой «Выполнить»: ему нужны данные от сайта. Повторный запуск `setup` не удаляет ответы, но заново оформляет служебные листы и восстанавливает формулы итогов. Не используйте названия «Ответы» и «Итого» для других данных.

## 3. Разверните веб-приложение

В Apps Script:

1. **Развернуть → Новое развертывание** (в некоторых версиях интерфейса — **Начать развертывание**).
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я** / ваш аккаунт.
4. У кого есть доступ: **Все** / **Anyone**, включая пользователей без Google-аккаунта. Не «Все пользователи с аккаунтом Google».
5. Нажмите **Развернуть** и скопируйте **URL веб-приложения**, заканчивающийся на `/exec`.

Пример структуры адреса (вместо него нужен ваш реальный адрес):

```text
https://script.google.com/macros/s/ВАШ_ID_РАЗВЕРТЫВАНИЯ/exec
```

Откройте реальный адрес в приватном окне без входа в Google. Должен появиться JSON:

```json
{ "ok": true, "service": "wedding-rsvp", "configured": true }
```

Если `configured` равен `false`, запустите `setup`. Если вместо JSON открывается вход в Google, проверьте доступ к веб-приложению. В рабочем/учебном аккаунте администратор может запретить анонимный доступ — тогда потребуется аккаунт, где это разрешено.

Это публичный адрес **приёма** ответов. Он не даёт посетителям чтение таблицы. Саму Google Таблицу не нужно публиковать или открывать всем по ссылке. Секретных ключей на сайте нет. Поскольку приём публичный, это не защита от целевого спама; для закрытого свадебного приглашения предусмотрены проверка полей и защита от повторных запросов, но не аутентификация гостей.

## 4. Укажите адрес в сайте

Откройте `src/config/rsvp.ts` и вставьте URL в `endpoint`:

```ts
export const rsvpConfig = {
  endpoint: 'https://script.google.com/macros/s/ВАШ_ID_РАЗВЕРТЫВАНИЯ/exec',
  timeoutMs: 30_000,
}
```

На локально запущенном сайте кнопка автоматически станет «Отправить ответ». Для опубликованного сайта выполните новую сборку и опубликуйте её на своём хостинге. Одного изменения локального файла для уже опубликованного сайта недостаточно.

## 5. Проверьте реальную отправку

1. Откройте приглашение в приватном окне, укажите имя «Тестовый гость», выберите два напитка и отправьте ответ.
2. Дождитесь «Спасибо! Ваш ответ получен» и убедитесь, что в листе **Ответы** появилась ровно одна строка.
3. Нажмите отправку ещё раз с теми же данными: новая строка появиться не должна, счётчики не увеличатся.
4. Проверьте лист **Итого**: выбранные напитки должны получить по одному ответу.
5. Проверьте «Свой вариант» и «Не буду пить» отдельными тестовыми анкетами.
6. Удалите только тестовые строки (не заголовки). Формулы итогов пересчитаются.
7. Повторите проверку с телефона на опубликованном сайте.

Пока адрес не добавлен и тест не проведён, подключение к реальной Google Таблице не проверено.

## Как получать результаты

- **Ответы**: дата, имя, отдельные столбцы напитков и текст своего варианта. Служебный ID скрыт в столбце A; не удаляйте его.
- **Итого**: количество ответов по каждому напитку. Можно выбрать несколько напитков, поэтому сумма предпочтений больше числа анкет.
- Передать организаторам: поделиться таблицей с конкретными адресами в режиме **Читатель** либо **Файл → Скачать → Microsoft Excel (.xlsx)**.
- Для CSV: выберите нужный лист, затем **Файл → Скачать → CSV**. Выгружается текущий лист.
- Не переименовывайте лист «Ответы» и не меняйте порядок или названия его столбцов. Для собственных расчётов создавайте отдельный лист.

Повтор неизменённой анкеты из того же браузера использует тот же ID. При изменении анкеты создаётся **новая строка**, старая не заменяется. Другой браузер или очищенное хранилище также создадут новую анкету. Исправления и дубли одного гостя проверяйте по имени вручную: имена не являются надёжными уникальными идентификаторами. Итоги считают анкеты, а не гарантированно уникальных людей.

## Если отправка не работает

- **Кнопка всё ещё «Сохранить ответ»**: `endpoint` пуст или опубликована старая сборка.
- **Запрос пришёл, а подтверждения нет**: проверьте `/exec` и анонимный доступ, доступность Google, затем повторите тот же ответ. При обрыве связи строка могла сохраниться; повтор использует тот же ID.
- **Ошибка CORS или HTML вместо JSON**: проверьте доступ в приватном окне и используйте именно адрес `/exec`, не `/dev` и не ссылку на таблицу. Не заменяйте запрос на `mode: 'no-cors'`: тогда невозможно узнать, сохранился ли ответ. Если на выбранном хостинге/в браузере чтение ответа всё ещё блокируется, потребуется серверный посредник на хостинге; сначала проверьте реальный деплой.
- **Нет новых строк**: в Apps Script откройте «Выполнения», проверьте ошибки, повторите `setup` и убедитесь, что заголовки листа не изменены.
- **Изменили Code.gs**: обновите существующее развертывание через **Развернуть → Управление развертываниями → Изменить → Версия: Новая версия → Развернуть**. Простого сохранения файла недостаточно. При обновлении существующего развертывания адрес обычно сохраняется.
- **Изменили список напитков на сайте**: синхронно обновите `DRINKS`, заголовки, запись строки и итоговые формулы в Apps Script. Текущая схема рассчитана на исходные семь вариантов.

## Как устроена отправка

`src/services/rsvp.ts` отправляет JSON в POST с Content-Type `text/plain` без cookies и дополнительных заголовков. Apps Script записывает строку под блокировкой и возвращает квитанцию с ID только после `SpreadsheetApp.flush()`. Сайт проверяет квитанцию; тайм-аут и недоступный ответ не считаются успехом. Пользовательский текст записывается так, чтобы не выполняться как формула.

Локальные проверки: `npm run test:rsvp`, `npm run build`, `npm run lint`.

## Исправление #ERROR! в старой версии листа «Итого»

Первая версия скрипта использовала COUNTIF с запятой между аргументами. В таблицах с другим региональным разделителем это могло приводить к ошибке разбора формулы. Новая версия использует формулы с одним аргументом, без запятых и точек с запятой.

Самый быстрый способ: на листе **Итого** один раз выделите ячейку **B3** (не переходите в режим редактирования) и вставьте следующие семь строк. Они заполнят B3:B9:

```text
=SUMPRODUCT(--('Ответы'!D2:D="Да"))
=SUMPRODUCT(--('Ответы'!E2:E="Да"))
=SUMPRODUCT(--('Ответы'!F2:F="Да"))
=SUMPRODUCT(--('Ответы'!G2:G="Да"))
=SUMPRODUCT(--('Ответы'!H2:H="Да"))
=COUNTA('Ответы'!I2:I)
=SUMPRODUCT(--('Ответы'!J2:J="Да"))
```

Или замените код Apps Script актуальным `Code.gs`, сохраните и вручную выполните **repairSummary**. Эта функция исправляет только B2:B9 на листе «Итого», не меняя ответы гостей. Для исправления формул не нужно обновлять веб-развертывание: обработчик отправки не изменился. Полезно сохранить исправленный код в редакторе, чтобы последующий запуск setup не вернул старые формулы.
