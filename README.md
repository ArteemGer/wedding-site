# Свадебное приглашение Ивана и Ангелины

Одна страница на React + TypeScript + Vite.

## Как редактировать

- `src/config/wedding.ts` — имена, дата с часовым поясом, город, адрес, пути к фотографиям, текст приглашения, напитки и цвета дресс-кода.
- `src/sections/` — отдельный компонент на каждый блок. Остальные заголовки и короткие подписи находятся в соответствующем блоке.
- `src/components/` — шапка и общий компонент фотографии.
- `src/App.tsx` — порядок блоков на странице.
- `src/styles/` — стили по блокам; `responsive.css` содержит адаптацию для телефона и планшета, `animations.css` — анимации.
- `src/index.css` — общие стили, шрифты и базовые настройки.
- `src/hooks/` — логика анкеты, таймера и появления блоков при прокрутке.
- `src/utils/` — восстановление анкеты и вычисление календаря из даты свадьбы.
- `index.html` — название вкладки и описание страницы для поисковиков; при изменении имён или даты обновите и их.

Фотографии положите в `public/photos/`, а в настройках укажите, например, `/photos/ivan-childhood.jpg`. Пустой путь показывает заглушку. Таймер считает до времени в `wedding.date`, сейчас это полночь 13 декабря по Москве; календарь и подписи дат используют ту же настройку.

## Анимации

Блоки плавно появляются один раз при прокрутке, фотокарточки и элементы формы реагируют на наведение. В `src/styles/animations.css` настраиваются длительность и плавность. При системной настройке `prefers-reduced-motion: reduce` эффекты отключаются. Содержимое остаётся доступным при отсутствии IntersectionObserver, а переход клавиатурой показывает блок сразу.

## Анкета

Готова интеграция с Google Таблицей через Apps Script. Инструкция: [integrations/google-sheets/SETUP.md](integrations/google-sheets/SETUP.md). Код для Google: [Code.gs](integrations/google-sheets/Code.gs). Адрес веб-приложения задаётся в `src/config/rsvp.ts`.

Пока адрес пуст, ответы сохраняются только локально под ключом `wedding-rsvp`. После подключения кнопка отправляет анкету и показывает успех только после подтверждённой записи. Повтор неизменённой анкеты с тем же ID не создаёт дубликат. Изменённая анкета создаёт новую строку; это не редактирование предыдущего ответа.

Проверка логики записи и подтверждения: `npm run test:rsvp`.
